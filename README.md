# Alagoas Medical - Institutional Website
US-EN

Institutional website developed for **Alagoas Medical**, a distributor of medical and hospital supplies located in Maceió, Brazil.

This project represents my **first real website published for an actual company**, deployed under a custom domain with integration of SEO tools and Google Business presence.

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Custom CSS animations
- Custom favicon
- Google Search Console + Sitemap
- Hosting via UOL Host (cPanel)

---

## About the Project

This project was **based on a free template** from TemplateMo (Kind Heart Charity) and adapted with:

- New visual and institutional content
- Full mobile responsiveness adjustments
- Addition of favicon, basic SEO, and Google indexing
- Fixes for mobile animation issues
- Deployment on hosting with custom domain and HTTPS

---

## Project Goals

- Learn how to work with real HTML website structure
- Practice template customization for institutional websites
- Understand full deployment with domain and HTTPS
- Learn the fundamentals of SEO and online presence
- Start building my web development portfolio
